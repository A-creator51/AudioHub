# 对项目的介绍

AudioHub让受支持的Windows/Android设备既可输入也可输出。所谓“去中心化”指不固定电脑作中心，而非无中心网络；创建者仍承担本房间混音分发。中心可不播放，中心退出不迁移。

共用Java引擎集中处理认证、角色、拓扑、增益、限额、混音和100Hz期限调度。共用离线HTML/CSS/JS界面在Windows WebView2和Android WebView显示。Windows由C++启动器加载用户安装的Java，JNI接WASAPI、RFCOMM和公开WinRT直接连接；Android接媒体捕获、AudioTrack、BluetoothSocket和前台服务。

局域网用TCP/TLS传48kHz双声道PCM，蓝牙房间用加密字节流/TLS/IMA1；房间临时证书固定指纹加密钥，码不持久化。无云、无账号，不保存音频；元数据日志仍可能有隐私。设备身份在用户本地配置生成，不应上传。

Windows直接连接是系统A2DP加可选端点回采，不是隔离A2DP解码器。Android不提供公开通用Sink支持，保留布局但禁用。最多5入5出不是硬件承载承诺，输出允许延迟，不严格同步。不支持中心迁移、自动重连、混合房间、桥接或按输出不同混音。

项目为个人非商业源码可见开发预览，作者标识A-creator51。第三方组件保留各自授权。请读免责声明，以低音量小规模测试，不能把自动回归当作硬件音质或安全认证。
