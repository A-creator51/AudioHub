# 使用说明

使用前阅读[免责声明](../DISCLAIMER.md)，先低音量单路测试。仅授权个人非商业使用。公开Windows包需要单独安装x64 Java21、设置JAVA_HOME及系统WebView2；Android10+。私有签名APK不能直接覆盖旧开发签名APK，升级前妥善备份，不要贸然卸载。

## 局域网

1. 两端连接能互通的局域网或热点，任一受支持设备可在局域网页选择正确本机IPv4创建房间。热点隔离、VPN、路由和防火墙可能阻止互通；软件不自动修改这些设置。
2. 通过可信私密途径分享本次AH2房间码，另一端粘贴加入。房间码含密钥，不能公开。默认TCP端口47162，不建议暴露公网。
3. 输入端选择声音来源，勾选“发送本机声音”即可发送，**不需要启用本机播放**。Android需要完成媒体捕获授权，Android14+选整个屏幕；授权不意味着读取屏幕图像，本项目仅处理声音。受保护或不允许捕获的媒体可能静音，不以麦克风兜底。
4. 每台设备自己的“本机输出”勾选播放端点并启用本机音频，默认输出25%。中心和成员语义一致。停用播放不影响发送；取消发送不影响播放；两个方向全停仍保持房间。
5. 中心统一调各输入增益，默认100%。所有输出收到同一混音。总览显示报告的端点，绿色为启用状态，不代表实际有声。
6. 房间最多5输入5输出（含中心）；Windows两个播放端点算两路，Android不保证多耳机独立并发。中心离开即关闭房间，无自动转移。

## 软件蓝牙

两端安装App并先在系统中配对，再创建/加入软件蓝牙房间。使用RFCOMM、TLS和IMA1编码。房间管理按创建、关闭/退出、刷新排列。Android12+需“附近设备”权限。Android中心码中地址为PAIRED，加入端须明确选择已配对中心；不会放宽指纹校验。

输入/播放开关与局域网一致。单设备只参与一个房间，不桥接LAN/蓝牙；5入5出为软件限额，不是无线容量承诺。新设备发现/配对由系统设置完成，刷新已配对列表不等于扫描到真实软件房间。

## 直接连接与回采

发送端无需安装AudioHub。Windows先系统配对，在直接连接框刷新选择来源后开启。活动软件蓝牙会话切换需确认；开启自动禁用软件蓝牙，退出恢复，不能抢占LAN。活动来源列表不能刷新，先退出再刷新。

可直接用WIN系统直出，不开启回采；需要软件多路播放时，在来源控件下方选择声音实际所在的回采端点并点“开启回采”，然后在本机输出选择多个**不同**播放端点并启用。上方回采与下方输入开关同步，不需重复勾选。关闭回采保留连接和当前播放；退出直接连接停止本路径两方向。

回采“刷新设备”只枚举音频端点，不断开来源；移除设备后保留失效选择要求重选。回采会包含同端点其他程序声音，不是独立隔离的A2DP PCM；原声不自动静音，也不修改系统默认输出。Android无公开通用A2DP Sink能力，直接连接和回采禁用，仍可使用软件蓝牙。

## 设置、全屏与安全

音量范围：蓝牙左、局域网右，选择后立即应用并单独保存，不误提交其他草稿。降上限会限制真实增益，升上限不自动提高音量。软件范围不控制WIN直出。超过100%可能削波，请低音量验证。

音频缓冲/MMCSS保存后下次启动音频生效；增大缓冲增加延迟，不能替代正确节奏或改善所有网络。F11/顶部按钮切无边框全屏，Esc恢复。启动不自动连接、采集、播放。

回绕保护：Windows回采端点不得同时作输出；Android排除本应用播放。虚拟声卡、第三方转发的间接回环可能无法识别，出现声音叠加立即停止。软件不读取麦克风、不保存音频、不自动静音原声，不改防火墙。

## 无声/断续排查

先分清连接、授权、采集、混音、播放。采集/非静音计数与电平为0，检查媒体策略与来源；中心收到静音不等于无线丢包。输出提交有非静音但无声，检查播放是否启用、真实设备路由和系统音量。TCP超时、TLS失败、房间认证失败是不同阶段。

日志仅记录诊断元数据，仍可能包含设备名、IP和系统路径。分享前脱敏，不提供房间码、完整原始日志或.env。本机连接自检不能替代跨设备实测；合成100Hz测试不代表无线音质验收。后台/锁屏与普通耳机共存需要真机测试，暂不承诺长期无人值守可用。
