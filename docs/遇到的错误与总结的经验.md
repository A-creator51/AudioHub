# 遇到的错误与总结的经验

- 无声不一定是传输失败：旧界面将采集和播放混淆。现输入和本机播放分别控制；通过包数、非静音、电平、真实路由逐段判断。
- 旧定时轮询在部分Windows环境仅消费约64帧/秒，低于10ms帧所需100Hz。修复为单调时钟绝对期限，短抖动有限补齐，长暂停重新定位。不能用扩大缓冲掩盖平均速率不足。
- 音量范围旧前端只标记草稿，后台也曾未限制真实增益；聚焦推子保留旧max。现独立命令实时限制并单独落盘，测试真实change事件、聚焦更新、两路独立和重启恢复。
- 热点/手机互连失败不能仅凭电脑VPN或防火墙定因。加入TCP/TLS/认证分段日志；自检通过仍不等于跨设备可达。不要删除指纹校验来掩盖故障。
- 宿主缺少窗口样式切换会使全屏有边框，已验证F11进入/Esc恢复。普通最大化不等于全屏。
- A2DP来源刷新可能影响连接，活动时禁止；回采刷新只查端点。切换需确认，不影响LAN。来源失效不自动换源，输入输出同端点被拒绝。
- 慢成员网络写入不能阻塞公共混音，发送队列有界且丢旧音频，持续控制拥塞只移除慢成员。合成字节流不是射频测量。
- 构建曾依赖个人磁盘和测试缓存路径。公开版一份共用代码，路径来自.env/PATH，浏览器来自npm或本机配置，源码不带真实日志/截图/身份。Windows脚本可用ASCII减少旧PowerShell编码歧义。
- Android仍有4项既有Lint警告（WebView JS、指纹TrustManager、备份建议、应用Context静态引用）；没有禁用检查来宣称零警告。真实无线试听、锁屏和满载未完整验收。

这些是可公开的技术经验，故意不包含真实用户设备、网络地址、绝对文件路径或会话记录。谨记免责声明不能代替安全实现与真实验证。
