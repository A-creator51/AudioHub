直接连接

直接连接使用标准 A2DP，发送端不需要下载或安装 AudioHub App。先在系统中配对，刷新并选择来源设备，再开启直接连接；开启后自动禁用软件内蓝牙房间，关闭后恢复。

直接连接模式可以选择 Windows（WIN）直出，也可以开启回采后多路输出。仅使用 WIN 直出时不必开启回采，由系统控制声音；需要 AudioHub 多路输出时，在此选择声音所在回采设备并开启回采，再到“本机输出”选择多个不同播放端点并启用。关闭回采不退出直接连接、不关闭已启用的本机播放。回采可能包含同端点其他程序声音；回采设备不能同时作为 AudioHub 输出。系统原声不会自动静音，也不会修改系统默认输出。Android 不提供公开通用的 A2DP 接收能力，不支持时相关控件禁用。

房间管理

新设备请先在系统蓝牙设置中发现并完成配对；此处仅枚举已配对设备，再通过 AudioHub RFCOMM 服务发现加入房间。Android 中心不公开本机 MAC，必须选择中心设备；证书指纹与房间密钥仍严格校验。一个设备只参与一个软件房间，不支持局域网/蓝牙混合房间。

房间管理

一台设备只参加一个房间；创建者是中心。中心退出后房间结束，不自动转移。AH2 不兼容旧 AH1。

本机输入

勾选立即启动向中心发送，取消勾选只停止发送，不影响本机播放。手机/平板首次开启需完成系统媒体捕获授权；打开程序或加入房间不会自动采集。

房间输入设备增益

中心统一管理各设备输入，默认 100%。超过 100% 可能削波。

本机输出

各播放设备音量

默认 25%，启用后可独立调节，不影响其他设备。中心和房间成员均在这里控制自己的扬声器、耳机等播放设备。

这里的启用/停用仅控制本机播放，不控制向中心发送。切换播放设备请先停用本机播放；发送仍继续。停止发送请取消上方“发送本机声音”。
回绕保护始终启用：Android 排除 AudioHub 自身播放；Windows 回采端点不得同时作为输出。不会读取麦克风、修改默认播放设备或自动静音原声。




运行日志
最近 500 条元数据；包含 TCP、TLS、认证阶段及音频诊断。不记录声音或房间码。设备名称、IP 可能包含个人信息。



 
启动与行为
只恢复已保存的设备选择、页面和参数，不自动开房、连接、采集或播放；房间码和密钥不保存。

 
音频缓冲与调度
缓冲与调度保存后下次启用本机音频生效。Android 使用音频线程优先级，MMCSS 仅 Windows 生效。较大缓冲提高容错但增加延迟；不同输出不保证物理同步。

 
蓝牙连接与编码
直接连接在蓝牙页开启/退出，使用标准 A2DP，与软件蓝牙房间互斥；切换活动蓝牙会话需确认，不会抢占局域网。
仅列出已实现的协议和编码；AHB2 严格协商 IMA1。单流编码负载约 390 kbps（不含 TLS/蓝牙开销），双向及耳机共存消耗更多带宽。5入5出是软件限额，不是已验证的蓝牙并发能力。

 
音量范围
选择后立即应用并单独保存，无需点击“保存全部参数”。
范围决定音量推子的最大值，不是音量本身。降低上限会即时降低超限增益，提高上限不会自动提高音量。超过 100% 可能削波。蓝牙范围包含直接连接的回采混音，不改变 Windows 系统直出音量；其他未保存参数不会随范围一起保存。

 
格式与安全
TLS 1.2 + 房间临时证书 SHA-256 固定指纹 + 128 位密钥。连接码持有即授权，仅分享给可信设备。无云、无账号、不保存音频、不安装驱动、不修改防火墙。
Android 媒体采集需系统授权，受应用捕获策略及 DRM 限制；后台、锁屏与特定硬件兼容性需要真机验证。间接虚拟路由、第三方转发产生的环路不在直接端点保护覆盖范围内。

 
断续诊断与对比
只记录时间、帧数和静音标志，不录音；静音标志不等于无线丢包。预设不改变蓝牙编码或无线码率。蓝牙协议与 A2DP 的后续改造保持独立。
创建房间后可检查本机 TCP / TLS / 认证。结果在日志页；不能代替跨设备实测。若双方无法连接，请分别导出中心端和加入端日志，不要提供房间码。
